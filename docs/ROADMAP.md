## 1. 레벨(스테이지) 모드 — 이번 확장의 핵심

한 판짜리 구조를 **정해진 시간 안에 목표를 깨는 레벨제**로 바꾼다. 클래식 모드는 "자유 모드"로 남겨둔다.

### 1-1. 기본 규칙
- 레벨마다 **목표 + 제한 시간 + 시작 보드(배치)** 가 정해져 있다. 레벨 데이터는 ScriptableObject(`LevelDatabase`)로 관리.
- 시간 안에 목표를 다 채우면 클리어 → 남은 시간에 따라 **별 1~3개** + 코인 보상.
- 실패하면: 재도전 / **광고 보고 +30초** / **쥬얼리로 +30초** (재화 구조와 연결)
- 홈 화면 GAME START → **레벨 지도(1, 2, 3 … 노드가 이어진 길)** 로 바뀌고, 다음 레벨이 열린다.
- 레벨 시작 보드는 랜덤이 아니라 **디자인된 배치**(목표 달성이 가능하도록).

### 1-2. 목표 종류 (레벨이 오를수록 하나씩 등장)
| 목표 | 예시 문구 | 처음 등장 |
|---|---|---|
| 머지 N번 | "머지 3번 하기" | Lv 1 |
| 특정 체인 머지 | "카페 아이템 5번 머지" | Lv 3 |
| 특정 단계 만들기 | "Bud(5단계) 만들기" | Lv 5 |
| 여러 목표 동시 | "머지 10번 + 베이커리 4단계" | Lv 8 |
| **햄스터 주문** | 햄스터 말풍선: "Iced Americano 1개, Croissant 1개" | Lv 10 |
| **박스 열기** | "박스 6개 열기" | Lv 15 |
| **거미줄 풀기** | "갇힌 아이템 4개 구하기" | Lv 20 |
| 잡초 치우기 | "잡초 5개 없애기" | Lv 25 |

### 1-3. 레벨 진행 예시 (초안)
| 레벨 | 목표 | 시간 | 보드 특징 |
|---|---|---|---|
| 1 | 머지 1번 | 60초 | 같은 아이템 2개만 놓여 있음 (튜토리얼) |
| 2 | 머지 3번 | 60초 | 같은 쌍 3개 |
| 3 | 머지 5번 (연쇄 머지 유도) | 90초 | 1단계 4개 → 2단계 2개 → 3단계 |
| 4 | Sprout(3단계) 만들기 | 90초 | |
| 5 | 카페 아이템 5번 머지 | 120초 | 체인 섞임 |
| 6~9 | 복합 목표 | 120~150초 | ADD ITEM 사용 필요 |
| 10 | 햄스터 주문 2개 | 150초 | 주문 첫 등장 |

## 2. 막힌 칸(보드 기믹) — 참고 이미지처럼 "박혀 있는" 느낌

| 기믹 | 모습 | 규칙 |
|---|---|---|
| **박스** | 칸 위에 나무 상자 | 안이 안 보임. **옆 칸에서 머지하면** 상자가 열리고 안의 아이템(또는 빈칸)이 나온다 |
| **거미줄(갇힌 아이템)** | 아이템이 반투명 거미줄에 덮임 | 아이템은 보이지만 **움직일 수 없음**. 같은 아이템을 그 위에 머지하면 풀려나면서 합쳐진다 |
| **잡초** | 칸에 잡초 덤불 | 칸을 막음(아이템 못 놓음). 옆에서 머지 2번 하면 제거 |
| **잠긴 칸** | 자물쇠 | 레벨 목표 일부를 채우면 열림 (보드 확장 연출) |

- 구현: 칸마다 상태(`CellState`: Empty / Item / Box / Web / Weed / Locked)를 두고, 머지가 일어난 칸의 **상하좌우 이웃**에 효과를 준다.
- 모델링(Max): 나무 상자, 거미줄 덮개, 잡초 덤불, 자물쇠 — 둥글둥글 스타일 유지.

## 3. 햄스터 주문(Order)

참고 이미지처럼 화면 상단 햄스터 옆에 **말풍선 주문서**가 뜬다.
- 주문: 아이템 1~3개 (예: "Iced Americano x1, Croissant x1"), 진행도 `0/2` 표시
- **아이템을 햄스터에게 드래그**하면 납품 → 햄스터가 기뻐하는 동작 + 코인
- 레벨 모드에서는 목표로, 자유 모드에서는 반복 수입원(일정 시간마다 새 주문)으로 쓴다.
- 나중에 손님 NPC(다른 동물)를 늘리면 "손님 수집"도 메타 요소가 된다.

## 5. 메타 게임 (장기 목표)

- **정원/온실 꾸미기**: 홈 화면 섬을 꾸미는 하우징. 레벨 클리어·도감 보상으로 얻은 화분·소품을 섬에 배치.
- **도감 영구 보너스**: 체인 하나를 11단계까지 다 모으면 영구 보너스 (예: 그 체인 머지 코인 +1).
- **코스튬 세트 보너스**: 꽃집/카페/베이커리/아이스크림 세트를 모두 입으면 보너스.
- **손님 수집**: 주문을 준 손님 동물들이 도감에 쌓인다.
